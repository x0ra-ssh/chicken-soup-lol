# chicken-soup-lol
a recipe for my manchow chicken soup lol, enjoy!


## Run and deploy

Open `index.html` locally to use the recipe. For offline caching, serve it over localhost or HTTPS.

To publish with GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

Once deployed: https://x0ra-ssh.github.io/chicken-soup-lol/

The site is plain HTML/CSS/JavaScript with no external dependencies.
